# Smart Canteen Management System

## About
A Java Swing desktop application connected to a MySQL database that simplifies canteen food ordering and order management.

## Features
- Student registration and login
- View available food items
- Place orders with simulated UPI payment
- View personal order history and order status
- Admin menu and order management
- Submit food ratings and comments
- View feedback from other students before ordering

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC

## Setup
1. Install JDK and MySQL Server.
2. Create the `smart_canteen` database.
3. Execute the database schema SQL file.
4. Configure the database URL, username, and password in `DBconnection.java`.
5. Add the MySQL Connector/J library.
6. Compile and run `Main.java`.
